# Project documentation

- [`product/requirements.md`](product/requirements.md) is the current product
  specification; [`product/README.md`](product/README.md) defines its lifecycle.
- [`plans/`](plans/README.md) contains implementation plans and their outcomes.
- [`adrs/`](adrs/README.md) contains architecture decision records.
- [`agents/`](agents/) contains task-specific guidance loaded progressively by
  coding agents.

Plans describe how a bounded change will be delivered. ADRs explain why a
durable architectural decision was made. A plan may produce one or more ADRs,
but the records serve different purposes and should link to each other rather
than duplicate content.
